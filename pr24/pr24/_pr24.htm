Практическая работа № 24
"Зачетная работа по языку C#"

Цель работы:
Продемонстрировать полученные навыки и знания по работе в языке программирования С#

Общее задание:

  1. Используя интегрированную среду разработки (IDE) Microsoft Visual Studio создать один solution и написать линейные программы используя ООП.
  2. Структура Вашего исходного кода исходя из полученного варианта должна состоять из одного solution с названием номера выполняемой ПР (PR24) и 3-х проектов в этом solution - главная консольная программа (например, consApp) с методом Main(), библиотека классов DLL (например, dllApp) и проект с unit-тестами.
  3. Идентификаторы названия проектов, переменных, методов и классов должны отражать суть и цель их использования, запрещено использование в качестве названия проектов зарезервированные клювые слова языка C#.
  4. Для каждого задания в варианте требуется разработать свой класс для хранения и обработки данных в соответствии с заданием по номеру Вашего варианта. Каждый класс должен быть в отдельном файле исходного кода. Классы должны быть небольшими, понятными и выполнять одну единственную функцию (Single responsibility principle). В классе может быть различное количество методов, название методов должно соответсвовать логике выполняемого кода, в нотации и стиля CamelCase (для языка C#)
  5. Все реализуемые классы должны распологаться в отдельной библиотеке DLL - библиотеки классов. Количество методов в классе может быть различным. Каждый метод класса должен принимать начальные значения (одно или несколько) и возвращать итоговое/ые значения из класса/метода. Для доступа к библиотеке DLL необходимо использовать консольное приложение, забирать начальные значения с консоли и передавать в методы классов. Результат работы каждого задания в варианте должен быть отображен на консоли. Названия главных пространств имен (Namespace) в библитеке классов, в приложении Console и unit-тестах обязательно должны быть разные.
  6. Для комментирования исходного кода проекта необходимо обязательно использовать документирующие комментарии языка C# (param, returns, summary) в каждом классе. Запрещено оставлять закомментированый код в проектах! Не используйте комментарии для пояснения очевидных действий в коде.
  7. Для каждого задания в варианте необходимо написать 3 различных unit-теста, каждый unit-тест должен покрывать все возможные потенциальные ошибки во время выполнения программы. Одинаковые тесты писать запрещено.
  8. Код на языке C# должен быть отформатирован по стилю оформления редактора кода в MS Visual Studio (никаких "лесенок" из кода быть не должно)
  9. ВНИМАНИЕ!!! В заданиях, где требуется работа с массивом(и) - обязательно вводить размер массива(ов) и значения элементов массива(ов) с консоли, реализовать возможность заполнения массива случайными числами, по указанию пользователя.
  10. Предусмотреть контроль ввода начальных значений на корректность/правильность (например, выход за диапозон указанных чисел/значений, деление на 0, ввод только положительных/отрицательных значений, ...). При возникновении непредвиденной ошибки приложение не должно аварийно завершать свою работу.
  11. Номер варианта для выполнения практической работы соответствует номеру студента/обучающегося по списку в учебном журнале группы.
  12. Материалы проекта обязательно сохранить на сервере в своей папке и в личном облачном хранилище.
